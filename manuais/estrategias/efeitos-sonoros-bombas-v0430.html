Bombas: som durante queda e explosão

Um módulo JavaScript bomb-fall-audio.js usa a Web Audio API para produzir um efeito de queda, cujo tom muda durante a descida. O som termina no impacto ou quando o projétil deixa de existir. No ponto de impacto, o módulo de efeitos cria explosão, partículas, onda de choque, respingo na água, número flutuante de HP e histórico de acertos.

O botão de áudio permite silenciar os efeitos. Há limite de efeitos simultâneos para preservar desempenho.

Como testar

  1. Abra o modo Comando do Almirante do pacote ZIP da v0.4.30.
  2. Abra o menu PAINÉIS e o painel Esquadrões RTS.
  3. Selecione Charlie — Bombardeiros, decole e assuma o grupo.
  4. Primeiro clique: prepara a área de queda prevista no mar, à frente do avião.
  5. Segundo clique: solta as bombas mantendo a altitude escolhida.
  6. Observe o projétil descer e ouça o som até o impacto; verifique partículas e dano flutuante se atingir um navio.
  7. Use o botão 🔊/🔇 para conferir o desligamento do som.

Estudo e limitações

Código didático do áudio · Código didático dos impactos · Menu de painéis.

O pacote local está pronto para testes, mas a execução gráfica e o áudio no Windows ainda requerem validação visual e auditiva. O jogo completo v0.4.30 ainda não foi publicado no branch principal; os links acima são patches e manuais. Os armamentos simulados são fictícios.
